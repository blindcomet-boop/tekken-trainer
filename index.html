초풍·웨이브 트레이너

철권8 키보드 입력 연습 · 60fps(1F = 16.7ms) 기준으로 입력을 잘라서 판정합니다

페이지를 한 번 클릭하면 키 입력을 받기 시작해요. 한/영 상태는 상관없어요.

현재 입력앞 = → 기준

n

입력 기록유지 프레임

    df → 2 간격, 최근 30회 (ms)위쪽이 최신

    초풍 풍신권(늦음) 실패 음영 = 게임에서 같은 프레임에 들어갈 수 있는 범위 (0에 가까울수록 확률 높음)

    앉아대시 1회당 걸린 프레임, 최근 40회막대 사이 틈 = 연속 끊김

    키 설정
    프리셋

    버튼을 누른 뒤 원하는 키를 누르세요. Esc는 취소. 이미 쓰는 키를 고르면 서로 바뀝니다.

    판정 방식
    • 초풍은 df가 들어온 바로 그 프레임에 2가 들어가야 합니다. 1F라도 늦으면 일반 풍신권입니다.
    • 브라우저의 프레임 경계는 게임과 어긋나 있어서, 판정 결과보다 df → 2 간격(ms)이 더 정확한 지표입니다. 간격이 0ms면 항상 같은 프레임이고, 8ms면 대략 절반, 17ms를 넘으면 절대 같은 프레임에 들어가지 않습니다.
    • 동시 입력 처리: 좌+우는 중립, 위+아래는 위(히트박스 방식). 게임 설정과 다를 수 있습니다.
    • 아래+앞+2를 같이 눌렀는데 패드나 버튼에 불이 안 들어오면 키보드가 그 조합을 못 받는 것(고스팅)입니다. 키 배치를 바꿔 보세요.
    • 웨이브는 입력 리듬만 잽니다. 너무 빠르게 치면 게임에서는 앉아대시가 다 나오지 않을 수 있으니 실제 게임에서도 확인하세요.
